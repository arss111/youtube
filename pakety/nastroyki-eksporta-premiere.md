# Настройки экспорта Premiere Pro для YouTube (1440p, 60 fps)

Сейчас у тебя стоит **CBR 80 Мбит/с**. Это втрое больше, чем рекомендует YouTube для 1440p60, поэтому файл и выходит ~20 ГБ. YouTube всё равно пережмёт видео, так что лишний битрейт только раздувает файл и замедляет загрузку.

## Основное
| Параметр | Значение |
|---|---|
| Формат | H.264 |
| Размер кадра | 2560×1440 — оставить. С 1440p YouTube включает более качественный кодек, и видео лучше выглядит даже при просмотре в 1080p |
| Частота кадров | 60 |
| Порядок полей | Прогрессивная развёртка |
| Цветовое пространство | Rec. 709. HDR-настройки не трогать, метаданные HDR10 — выключены |

## Параметры кодирования
| Параметр | Значение |
|---|---|
| Производительность | Аппаратное ускорение — можно оставить, так быстрее |
| Профиль | **Высокий (High)**. Сначала сними галочку справа, иначе поле не меняется |
| Уровень | 5.1 |
| Кодирование | **VBR, 1 проход** (с аппаратным ускорением; при программном можно 2 прохода) |
| Целевой битрейт | **24 Мбит/с** |
| Максимальный битрейт | **30–35 Мбит/с** |
| Интервал между ключевыми кадрами | Включить галочку → **30** (половина частоты кадров) |

## Аудио
| Параметр | Значение |
|---|---|
| Формат | AAC |
| Частота | 48 000 Гц |
| Каналы | Стерео |
| Битрейт | **320 кбит/с** |

## Громкость (важно — сейчас видео тихое, −23 LUFS)
Вкладка **«Эффекты» → «Нормализация громкости»**:
- стандарт: ITU BS.1770-3;
- целевая громкость: **−14 LUFS**;
- допуск: 1 LU;
- макс. истинный пик: **−1 dBTP**.

## Что получится
- 24 Мбит/с × ~21 минута ≈ **3,7 ГБ** вместо ~20 ГБ. Качество на YouTube то же.
